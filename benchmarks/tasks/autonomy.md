# Intermediate-project brief — local work planner

I freelance alone and need a useful LOCAL project/work planner, not a SaaS platform. There are no other users, tenants, external providers, production credentials or real client data. I'd like to create projects and tasks, estimate effort, set optional due dates and dependencies, see what's blocked, mark work done and get a practical suggestion for what to do next. A task with unfinished prerequisites must not be completable. Deleting something must not silently leave broken dependency references. Cycles are invalid. State must survive a restart.

An easy-to-use documented CLI is sufficient; no UI/web server is required. I need to inspect a project overview, import/export synthetic project data and recover my saved work from a backup. Malformed import must not destroy the current state. Choose reasonable semantics for priorities, optional dates and a deterministic next-work suggestion; explain consequential assumptions briefly. Use Python or Node standard library only, no packages, no network. Choose the storage, command layout and code architecture yourself. Prefer an understandable intermediate-size application over a framework/platform project. Give actual start/test commands and run behavior tests.

Please demonstrate it with an entirely synthetic example containing two projects, at least six tasks, a dependency chain, a blocked task and a completed task. Show that a fresh invocation reads the saved state, a malformed import leaves it intact, cycles are rejected, a valid backup can restore the same state, and the next-work suggestion excludes blocked/completed tasks. Import/export may use the schema you choose; document it with an example fixture in the repository.

Future ideas, NOT authorized now: recurring tasks, collaboration/accounts, a web dashboard, sending reminders, cloud deployment. You may choose ordinary reversible implementation details without asking me. Ask only for a truly consequential unanswered product decision; otherwise state assumptions and deliver the working tool, including truthful limits.
