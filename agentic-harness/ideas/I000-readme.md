# Ideas als Änderungsakte

**Zuständigkeit:** Anlass, Optionen, Scope und Teilaufgaben größerer/unklarer Vorhaben; nicht das lebende Soll der Specs.

Idea nötig bei offenem Entscheidungsbedarf, mehreren getrennt prüfbaren Schritten/mehreren Sitzungen oder mehreren betroffenen Bereichs-Specs. Mehrere Dateien allein sind kein Grund. Kleine Iterationen und Refactors ohne Entscheidungsbedarf laufen direkt über den Auftrag.

```text
Offen → Klärung + Auftrag → Beauftragt → ganzer Umfang geprüft → Umgesetzt → Archiv
  └───────────────→ Zurückgestellt / Verworfen (mit Grund) → Archiv
```

Klarer direkter Umsetzungsauftrag genügt für „Beauftragt“. Ohne Auftrag keine Umsetzung. Bei Klärung Alternativen, Machbarkeit, betroffene Specs/Docs und offene Entscheidungen prüfen. AK/Nachweise nur in Specs, Idea verlinkt sie. Teilaufgaben einzeln nachweisen/abhaken; Arbeitsstand für Fortsetzung halten. Eine geklärte Idee ist keine Freigabe.

Template: `harness/templates/idea.md`, IDs fortlaufend. Bei vollständigem Abschluss Ergebnis/Verweise eintragen, nach `ideas/archiv/` verschieben. Bei Release/Meilenstein offene Ideas auf Aktualität und Status prüfen. Ältere `Draft` = Offen, `Ready` = geklärt, nicht beauftragt.
