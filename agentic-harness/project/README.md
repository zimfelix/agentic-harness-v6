# Projektdateien

`brief.md` ist eine optionale Ausgangsbeschreibung; Themen und Klärung gehören zu `harness/init.md`. Neue Projektthemen nur bei Bedarf nach `document-contract.md`. Erledigte Harness-Learnings können in `learnings-archiv.md` liegen. Diese Produkt-/Historieninhalte werden nicht exportiert; nur diese README bleibt Teil der Vorlage. Der laufende Projektstand liegt in `harness/project.md`, beauftragtes Verhalten in `specs/` nach `specs/S000-readme.md`. Hier keine zweite Spec-Definition oder Kopie des Projektprofils anlegen.
